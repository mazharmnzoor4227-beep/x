## 5. Ranked fix list

1. **Wire Fraunces + Outfit fonts (contract §Fonts, unfulfilled).** Download OFL static instances into `app/src/main/res/font/`, wire `Type.display` (Fraunces) + UI sans (Outfit) in `Theme.kt`, keep Google Sans Code mono only. Currently zero references; the Dots redesign's typography is silently system-default. Evidence: `app/src/main/res/font/` = `google_sans_code.ttf` only; grep `Fraunces|Outfit` = 0 hits.
2. **Delete or re-wire dead `IdeasStore`/`GoalsStore` and decide Idea Catcher's fate.** They are unreachable stores with a roster agent (`store-ideacatcher`) promising a capability whose UI was deleted. Either restore minimal Ideas/Goals capture inside chat, or remove the seed + stores. Evidence: `data/IdeasStore.kt`, `data/GoalsStore.kt`, `AxionApp.kt:54,56`.
3. **Wire Piper Urdu Aegis (or record the decision not to).** The user's standing natural Hindi-Urdu voice has zero presence in the tree; the live natural voice is online Edge neural (Uzma/Asad) + Gemini. If offline Piper is still wanted, add the engine + voice pack + Settings preference; if Edge is the new standing choice, record it and stop citing Piper. Evidence: grep `piper|aegis` = 0 hits tree-wide.
4. **Add the missing approval scope "This chat".** Dialog currently offers only Deny / Always allow / Allow once (`ui/chat/ChatScreen.kt:389-417`); the Grok trio's middle option — allow for this conversation only — has no equivalent, so users must choose between once and forever. Evidence: `agent/ApprovalGate.kt:8` enum has no chat-scoped decision.
5. **Restore a diff-review surface (or accept chat-only review).** `PatchEngine`/`ChangeGate` work, but their UI was deleted with `CodeDiffScreen`/`ReviewChanges`; the contract kept engine-only review, so large builds now get approved sight-unseen in chat text. Smallest fix: a chat-card rendering of `ChangeGate` before/after + Approve/Reject (the old `pendingReview` flow in `ChatViewModel.kt:444` still references it).
6. **Fix the Invite pill or remove it.** It is the only mock-only UI left on the main screen (`ChatScreen.kt:237-246`): a pill that opens a note saying sharing needs an account, with no share path. Either wire real share (chat export link) or drop the pill.
7. **Audit the surviving `Section.BUILD` path.** `ChatViewModel.kt:269` sets `section = Section.BUILD` when opening a project; confirm no Build-mode UI can resurface and that old BUILD conversations still open cleanly in the single chat screen.
8. **Rewrite the stale docs.** `docs/BUILD-STATUS.md` (Sand/206 files/41 routes/19 screens), `FEATURE-MAP.md` (18 skills), `docs/AGENT-ROSTER.md` (§3 18 packs; Idea Catcher "unblocked") all contradict the live tree. One pass to bring them to Dots / 30 skills / one-chat-screen reality.
